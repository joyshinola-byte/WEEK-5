**Week 5 – Payment Transaction Management System**

**Project Overview**

The Payment Transaction Management System is designed to store and manage customer payment details in an e-commerce database. 
It records payment information, tracks transaction status, and maintains payment history.

**Objectives**

- To create a Payment table with appropriate constraints.
- To establish a one-to-one relationship between Orders and Payment.
- To store different payment methods.
- To manage successful, failed, and pending transactions.
- To generate payment and revenue analysis reports.

**Technologies Used**

- Database: MySQL
- Language: SQL

**Modules**

1. Payment Table Creation
2. Payment Details Insertion
3. Transaction Status Management
4. Payment Mode Analysis
5. Revenue Analysis
6. Customer Payment History

**Key Features**

- Unique Payment ID for each transaction.
- Foreign key connection with the Orders table.
- Supports UPI, Credit Card, Debit Card, Net Banking, and Cash on Delivery.
- Tracks Success, Failed, and Pending payments.
- Generates payment-related business reports.

## Conclusion
This project helps manage e-commerce payment transactions efficiently. It maintains accurate payment records, 
tracks transaction status, and provides useful reports for business analysis.
